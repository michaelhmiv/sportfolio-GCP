# Legacy Sportfolio Repository

This repository contains an obsolete historical Sportfolio deployment snapshot and is not the canonical production source tree.

The maintained application repository is `michaelhmiv/Sportfolio`. Do not deploy this repository, treat it as current infrastructure documentation, or add credentials to it.

Because this repository is a public duplicate of application code, keeping it public expands the security, dependency, and licensing surface. After confirming that no active deployment, build pipeline, or rollback procedure depends on it, the repository owner should archive it or make it private.

Earlier copies were published with MIT license metadata. Archiving or changing later notices does not revoke rights that recipients validly received for those historical versions.
